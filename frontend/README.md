# Billing & Inventory Management System

A full-stack Billing and Inventory Management System built using React.js, Node.js, Express.js, and MySQL.

---

# Features

## Authentication
- User Login
- User Registration
- Secure Authentication

## Product Management
- Add Products
- Edit Products
- Delete Products
- View Products
- Stock Management
- Low Stock Alerts

## Billing System
- Create Bills
- GST Calculation
- Quantity Management
- Save Bills
- Invoice Generation

## PDF Invoice
- Download Professional Invoice PDF
- Clean Invoice Design

## Dashboard Analytics
- Revenue Analytics
- Category Distribution
- Monthly Revenue
- Top Selling Products
- Total Revenue Overview
